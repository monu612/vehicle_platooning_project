## 2026-10-21 - CI Pipeline Strictness
**Learning:** The GitHub CI pipeline is extremely strict, and will fail if any `flake8` errors from `--select=E9,F63,F7,F82` are present, even if they aren't part of the changes made. Additionally, it requires an `environment.yml` for conda. If `global` variables are declared but not assigned to, it triggers an F824 error. If a global variable is only read and not modified inside a function, the `global` declaration is unnecessary and should be removed. Self-assigning a variable to trick a linter degrades code quality and maintainability and is an anti-pattern.
**Action:** When working on performance optimizations, ensure that any existing critical linting errors blocking the CI are resolved and dependencies are correctly configured, even if they seem out-of-scope for the primary task. Be careful to resolve linting errors correctly without introducing hacks.
