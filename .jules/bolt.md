## 2026-09-01 - Optimizing tight loops in Python ACO routing
**Learning:** In the network routing simulation, the `_path_score` function accounted for ~10% of total runtime because it is called in a tight loop for every simple path generated during ant colony pathfinding. In Python 3.10+, using `itertools.pairwise(path)` completely avoids the O(N) memory allocation and overhead of list slicing associated with `zip(path, path[1:])`, reducing execution time significantly. Furthermore, inlining generic dictionary lookup helper functions (e.g., `_edge_metric` that performs `float(edge.get(name, default))` and bounds checking) directly inside the loop drastically reduces Python function call overhead, cutting execution time by nearly half.
**Action:** Always prefer `itertools.pairwise` over `zip` with slicing when iterating over consecutive sequence pairs in performance-critical sections. Unroll or inline small wrapper functions in tight loops to avoid function call overhead when operating on large datasets or graph metrics.
