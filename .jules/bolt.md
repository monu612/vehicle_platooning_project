## 2024-03-24 - Precomputing Paths for Performance
**Learning:** For pathfinding on dynamic networkx graphs, never cache generator-based algorithms (like nx.all_simple_paths) directly onto the dynamically mutating graph object (e.g., G._path_cache), as it causes stale caches, ignores cutoff constraints, and risks memory exhaustion. Instead, fully pre-populate the paths cache using the pristine static base topology before the simulation loop begins (avoiding lazy-loading inside the loop where only the mutated graph is available), and filter them dynamically per iteration by verifying that every consecutive edge still exists.
**Action:** When working with dynamic simulations that modify graphs per-iteration, identify pathfinding queries and pre-calculate all possible simple paths from the base topology. Then, on each iteration, quickly filter the precalculated paths against current edge availability to save substantial runtime.
