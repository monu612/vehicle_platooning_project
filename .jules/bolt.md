## 2024-10-03 - [Inlining function lookups avoids nested function call overhead]
**Learning:** In a high-frequency function like `_path_score` inside the ACO (Ant Colony Optimization) implementation, using small wrapper functions like `_edge_metric` that contain generic dictionary lookups and bounds checking (e.g. `min`/`max`) adds significant function call overhead.
**Action:** Inline these dictionary `.get()` lookups and replace built-in `min()` / `max()` operations with simpler ternary conditional logic (e.g., `val if val > min_val else min_val`) directly inside the critical loop to speed up overall execution without breaking compatibility or readability. Do the same for pheromone clamping functions when possible, while keeping the external API wrapper for less critical uses or to satisfy backward compatibility constraints like existing tests that depend on those specific signatures or default behaviors (e.g. keeping `alpha=1.0` and `beta=1.0` as defaults on `select_path`).
