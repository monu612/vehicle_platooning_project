## 2026-09-05 - Inlining edge metrics retrieval
**Learning:** Calling a wrapper function (`_edge_metric`) iteratively inside the tight loops of ACO path scoring significantly degrades performance. Precomputing static baseline metrics and converting Python's `min()` / `max()` built-ins to inline ternary conditional operators further bypasses the Python function call overhead and accelerates execution. Pre-computing paths for the dynamic graph cannot be done via simple caching during dynamically broken topology states since it might permanently omit temporarily broken paths.
**Action:** Replace iterations in `_path_score` inside `aco.py` with inline type conversions and inline clamping (e.g. `latency = l_val if l_val > MIN_EDGE_COST else MIN_EDGE_COST`), and precompute pristine base simple paths ahead of any dynamic graph perturbations to provide a pool of candidate simple paths during network disruptions.
