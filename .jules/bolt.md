## 2026-08-16 - Precomputing simple paths on the pristine static base topology
**Learning:** For pathfinding on the dynamic networkx graph, it is critical to precompute simple paths on the pristine static base topology *before* any dynamic mutations occur, and filter them by verifying every consecutive edge exists. Do not use lazy initialization during a dynamically disrupted state, as it permanently omits paths that are temporarily broken. Also, inlining wrapper functions or accessors in tight loops avoids significant Python function call overhead.
**Action:** When working on ACO pathfinding (`aco.py`), use `nx.all_simple_paths` on the static topology initially to cache all possible paths. Then, in `select_path`, iterate through these precomputed paths and filter those where all edges exist in the mutated graph `G_temp`, rather than running `nx.all_simple_paths` on `G_temp` directly which is expensive and redundant since the topology only mutates by edge removal, never edge addition.
