## 2026-09-06 - Precomputing simple paths and inlining metrics access
**Learning:** In a dynamic NetworkX graph simulation where link states change frequently but the node topology remains fixed, recalculating `nx.all_simple_paths` on every iteration is a massive bottleneck. Precomputing these paths once on the initial static topology and filtering them later (by checking if edges exist) during dynamic phases provides a significant speedup. Additionally, inlining dictionary lookups with fallback values and replacing standard `min()`/`max()` functions with inline ternary operations inside extremely tight loops (like path scoring over millions of edges) avoids huge Python function call overhead and drastically improves execution speed.
**Action:** Always precompute simple paths on pristine static topologies before dynamic mutations occur, and filter them by verifying endpoints and edge validity during the dynamically disrupted state. Avoid using `min()`/`max()` or separate helper methods for attribute extraction inside hot loops; use direct dictionary `.get()` with inline ternary bounds instead.
