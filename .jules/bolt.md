## 2026-09-01 - Optimizing tight loops in Python ACO routing
**Learning:** In the network routing simulation, the `_path_score` function accounted for ~10% of total runtime because it is called in a tight loop for every simple path generated during ant colony pathfinding. Inlining generic dictionary lookup helper functions (e.g., `_edge_metric` that performs `float(edge.get(name, default))` and bounds checking) directly inside the loop drastically reduces Python function call overhead, cutting execution time by nearly half. I initially tried `itertools.pairwise` to avoid `zip` slicing overhead, but that required Python 3.10+ and broke backwards compatibility with the older Python environment the CI uses, highlighting the need to verify minimum Python versions before applying standard library optimizations.
**Action:** Unroll or inline small wrapper functions in tight loops to avoid function call overhead when operating on large datasets or graph metrics. Always ensure Python standard library optimizations (like `itertools.pairwise`) are compatible with the target environment's Python version.
