## 2026-07-08 - Precomputing NetworkX Simple Paths on Dynamic Graphs
**Learning:** In simulations where the graph topology changes dynamically (e.g., edges are removed per iteration to simulate failures), calling `nx.all_simple_paths` repeatedly inside the simulation loop is a massive performance bottleneck. Re-calculating all paths every iteration is expensive.
**Action:** Pre-compute all simple paths once on the pristine (original) static graph before the simulation loop begins. During each iteration, instead of recalculating paths on the dynamic graph, filter the pre-computed paths to include only those whose edges currently exist in the temporary graph (`[p for p in precomputed_paths if all(G.has_edge(u, v) for u, v in zip(p, p[1:]))]`). This completely eliminates the need for expensive path recalculation while correctly handling temporary link failures.
