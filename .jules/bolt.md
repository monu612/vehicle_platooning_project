## 2024-05-24 - [Precompute static paths in dynamic graphs]
**Learning:** [In a dynamic graph simulation where only edge properties (like presence/absence or weights) change but the overall node and edge topology is static, repeatedly calling pathfinding algorithms like `nx.all_simple_paths` on the dynamically changing graph is extremely slow. Recomputing the paths within the simulation loop causes massive overhead.]
**Action:** [Precompute all simple paths on the pristine static graph topology *before* the dynamic simulation loop begins. During the simulation iterations, instead of running `nx.all_simple_paths` on the dynamic graph, simply iterate over the precomputed static paths and verify if all consecutive edges in the path exist in the current dynamic graph state (e.g., `all(G.has_edge(u, v) for u, v in zip(path, path[1:]))`).]
