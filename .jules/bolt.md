## 2025-02-20 - [NetworkX Dynamic Graph Pathfinding Context]
**Learning:** For pathfinding on the dynamic networkx graph, `nx.all_simple_paths` can be expensive if computed repeatedly on every iteration of a dynamically mutating graph. In `aco.py`, `select_path` calls `nx.all_simple_paths` dynamically without precomputing or filtering, which could be a significant performance bottleneck during simulations. The codebase memory explicitly states: "For pathfinding on the dynamic networkx graph, precompute simple paths on the pristine static base topology *before* any dynamic mutations occur, and filter them using `G.has_edge()`. Do not use lazy initialization during a dynamically disrupted state, as it permanently omits paths that are temporarily broken."
**Action:** When optimizing pathfinding, pass or maintain a precomputed list of static paths and validate them against the current topology, rather than computing `all_simple_paths` from scratch each time.
