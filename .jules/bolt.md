## 2026-11-08 - ACO Path Precomputation
**Learning:** In dynamic graph environments (like simulating link failures per iteration), caching paths directly using generator functions (e.g. nx.all_simple_paths) inside a hot loop is inefficient, especially when only some edges fail per iteration and the underlying topology changes. Instead, fully precomputing the paths from the base master graph `G` before the loop and dynamically filtering those cached paths inside the loop per iteration significantly improves performance.
**Action:** When working on pathfinding optimizations over dynamic networks, avoid repeating `nx.all_simple_paths` directly on a changing subgraph if the path source and target remain constant and the edge mutations are only removals/weight changes. Precompute all paths from the base static topology once, and conditionally filter them based on edge existence dynamically during each iteration.
